# Sneh Desai — Data Science & Analytics Portfolio

A responsive, single-page personal portfolio built with HTML, CSS, and a small amount of JavaScript. The visual style uses a dark navy background with teal accents and is designed to present both data science and analytics work. No build tools or package installation are required.

## 1. Preview the website on your computer

1. Download and extract `sneh-portfolio.zip`.
2. Open the `sneh-portfolio` folder.
3. Double-click `index.html` to open it in your browser.
4. Check the links, contact details, work history, and resume before publishing.

## 2. Publish with GitHub Pages (free)

### Recommended: use a user-site repository

1. Sign in to GitHub at https://github.com.
2. Create a **public** repository named exactly `Sneh14202.github.io` (GitHub usernames are case-insensitive; use the username shown on your profile).
3. Open the new repository and choose **Add file → Upload files**.
4. Upload the *contents* of this folder: `index.html`, `styles.css`, `script.js`, and the `assets` folder. Make sure `index.html` is at the repository root, not inside another nested folder.
5. Commit the files to the `main` branch.
6. Open **Settings → Pages**. If needed, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
7. Wait a few minutes, then open `https://Sneh14202.github.io`. GitHub may take several minutes to publish the first deployment.

### Alternative: use a project repository

You can instead create a repository such as `data-science-portfolio`, upload the same files to its root, and enable Pages in **Settings → Pages**. The URL will then include the repository name, for example `https://Sneh14202.github.io/data-science-portfolio/`.

## 4. Files in this folder

- `index.html` — portfolio sections and text
- `styles.css` — colors, layout, responsiveness, and visual styling

- `assets/Sneh_Desai_Resume.pdf` — resume download/view file

## 5. Beginner-friendly editing guide

- To change wording, links, or project descriptions, edit `index.html` using VS Code or another text editor.
- To change colors, edit the CSS variables at the beginning of `styles.css` (`--bg`, `--panel`, `--text`, and `--accent`).
- To update the resume, replace the PDF in `assets` with a new PDF using the same filename.
- After each change, save the file and refresh your browser to preview it.
